# Python ETL – Hospital Data Cleaning

This folder contains the Jupyter Notebook used for data cleaning and transformation as part of the Hospital Analytics Project.

## File Included

- `Hospital_Data_Cleaning.ipynb` – Notebook containing the Python ETL workflow.

## Tools & Libraries

- Python
- Pandas
- NumPy (if used in the notebook)
- Jupyter Notebook

## Key Activities

- Loading raw healthcare CSV datasets.
- Inspecting dataset structure and data types.
- Identifying and handling missing values.
- Checking duplicate records.
- Cleaning and standardizing column names.
- Transforming data and preparing it for MySQL.
- Exporting cleaned datasets for database loading.

## How to Run

1. Install Python and Jupyter Notebook.
2. Install the required libraries.
3. Download the source datasets using the instructions in `01_Raw_Data`.
4. Update the file paths in the notebook if necessary.
5. Open and execute `Hospital_Data_Cleaning.ipynb`.
