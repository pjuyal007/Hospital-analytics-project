# Hospital Analytics Project – Workflow Screenshots

This folder contains screenshots documenting the end-to-end workflow followed during the development of the Hospital Analytics Project.

The screenshots provide visual evidence of the key stages, from raw healthcare data preparation to database development and interactive dashboard creation.

## Project Workflow

### 1. Python ETL
- Loading and inspecting raw healthcare datasets.
- Cleaning missing values, duplicates, column names, and data types.
- Transforming and exporting cleaned datasets using Python and Pandas.

### 2. MySQL
- Creating the hospital analytics database and relational tables.
- Defining primary keys and foreign key relationships.
- Loading cleaned datasets and validating records.
- Performing basic and advanced SQL analysis.

### 3. Power BI
- Transforming data using Power Query.
- Creating relationships in the data model.
- Developing DAX measures and KPIs.
- Building interactive dashboards with slicers and visualizations.

## Tools & Technologies
- Python
- Pandas
- MySQL
- Power BI
- Power Query
- DAX

Each subfolder contains screenshots of the corresponding project development stage.
