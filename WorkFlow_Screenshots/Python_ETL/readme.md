# Python ETL Workflow Screenshots

This folder contains screenshots documenting the Python-based ETL process performed for the Hospital Analytics Project using **Python and Pandas**.

## Screenshots

### 1. Data Loading & Inspection
Shows how the raw healthcare CSV files were loaded into Pandas DataFrames and inspected to understand their structure, columns, data types, and record counts.

### 2. Data Cleaning
Shows the data-cleaning process, including handling missing values, checking duplicate records, standardizing column names, and correcting data types.

### 3. Data Transformation & Export
Shows the final data preparation and validation steps, followed by exporting the cleaned datasets for loading into the MySQL database.

## Tools Used
- Python
- Pandas
- Jupyter Notebook

These screenshots provide visual evidence of the data preparation stage before database loading and further analysis.
