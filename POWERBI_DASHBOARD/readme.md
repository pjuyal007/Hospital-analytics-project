# Power BI Dashboard – Hospital Analytics

This folder contains the interactive Power BI dashboard developed as part of the Hospital Analytics Project.

The dashboard presents insights into patient demographics, hospital encounters, healthcare costs, payer coverage, and clinical activities.

## Files Included

| File | Description |
|---|---|
| `Hospital_Analytics.pbix` | Power BI Desktop project file containing the interactive dashboard. |
| `Hospital_Analytics.pdf` | PDF export of the dashboard pages for easy viewing. |

## Dashboard Pages

1. **Hospital Overview** – Provides a high-level summary of hospital data, patient count, encounters, and key trends.
2. **Patient Demographics** – Explores patient age groups, gender distribution, location, and demographic characteristics.
3. **Encounters & Operations** – Analyzes hospital visits, encounter types, duration, and organizational activity.
4. **Healthcare Costs & Payers** – Presents healthcare expenses, payer coverage, and related cost analysis.
5. **Clinical Insights** – Explores conditions, allergies, procedures, immunizations, and imaging activities.

## Tools Used

- Microsoft Power BI Desktop
- Power Query
- DAX
- Data Modeling

## How to Explore

- Open `Hospital_Analytics.pbix` using Power BI Desktop.
- Configure the data source connection if required.
- Refresh the data if the source files are available.
- Navigate through the five dashboard pages and use the interactive filters and slicers.
